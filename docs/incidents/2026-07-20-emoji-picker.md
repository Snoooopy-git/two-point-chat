# Emoji Picker 集成故障复盘

日期：2026-07-20

## 影响

表情选择器经历多次修复才恢复可用，期间出现无法加载、空白和点击无响应。

## 独立根因

1. 默认 CDN 在目标网络不可达。
2. Vue 未将 `emoji-picker` 声明为 Web Component。
3. 组件首次挂载位置不可见，导致内部布局测量失败。
4. 挂载后手工绑定事件存在初始化时序竞态。

## 流程根因

- 未先建立最小可复现环境；
- 未系统列出第三方库、网络、框架集成和布局假设；
- 每次只处理当前症状，导致其他根因依次暴露；
- 未在首次处理时检索上游已知问题。

## 永久措施

- Web Component 必须配置 `isCustomElement`。
- 使用 Vue 模板事件绑定。
- 首次挂载必须处于可见区域。
- 第三方集成问题先建立最小复现，再检查上游文档和已知问题。
- 修复必须覆盖网络、库本身、框架集成、布局和事件五个层次。
